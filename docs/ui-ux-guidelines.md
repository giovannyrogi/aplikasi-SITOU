# Pedoman UI/UX SITOU

Ini indeks aturan frontend, bukan daftar bacaan wajib seluruhnya. Pada tugas frontend, pilih fondasi yang terdampak dan koreksi fitur terkait. Cari heading/komponen lebih dulu. Gunakan aturan yang sudah dibaca sampai ada perubahan sumber, perpindahan cakupan atau konteks yang tidak lagi memuatnya, sesuai [AGENTS](../AGENTS.md#baca-sesuai-tugas).

## Pilih aturan yang relevan

| Perubahan | Pemilik aturan |
| --- | --- |
| Tema, font, spacing, tabel, form dan kontrol bersama | [Fondasi visual](ui/foundations.md) |
| Modal, header/footer, scroll, konfirmasi dan snackbar | [Modal dan feedback](ui/modals.md) |
| Judul, label, petunjuk, istilah dan pesan | [Bahasa](ui/language.md) |
| Pola UX baru, referensi desain, rencana state dan verifikasi | [Workflow desain](ui/workflow.md) |
| Jadwal tetap/shift, penetapan dan perubahan harian | [Koreksi jadwal](ui/schedules.md) |
| Katalog, kalender dan PDF SKB | [Koreksi kalender](ui/holidays.md) |
| Profil, pendidikan dan data Pegawai | [Koreksi Pegawai](ui/employees.md) |
| Inventaris, transaksi dan stok | [Koreksi Inventaris](ui/inventory.md) |
| Sidebar, akun, akses dan dashboard | [Koreksi akses/dashboard](ui/access-dashboard.md) |
| Peta lokasi dan indikator absensi | [Koreksi lokasi/absensi](ui/attendance.md) |

## Sumber lain berdasarkan fungsi

API/props komponen berada di [indeks komponen](../app/components/README.md). Aturan bisnis dan kontrak server dipilih melalui [indeks domain](README.md). Skill hanya mengatur urutan penerapan, bukan menyimpan salinan kebijakan. Catat koreksi baru satu kali di dokumen pemilik pada tabel di atas; jangan menambahkannya lagi ke AGENTS atau skill. Rujukan/tanggal sumber desain tetap tersedia pada workflow dan section fitur terkait.
