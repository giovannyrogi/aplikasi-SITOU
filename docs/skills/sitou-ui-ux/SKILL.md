# SITOU UI/UX workflow

Use the frontend route in the checkout's AGENTS.md and documentation index. Load only the guidelines, component-reference section and feature contract required by the current change. State the user's task, the intended information order and the affected shared component before editing. Apply the documented corrections, then implement and verify the relevant states and render. Record any new user decision in its owning project document, not in this skill. The repository rules define exact controls and checks; do not repeat them here or read unrelated operational guides.

Compare action variants, colors, and typography with an existing screen that serves the same purpose. Use the [visual foundations](../../ui/foundations.md) to resolve differences. For media galleries, verify that each caption matches its state and that opening the image works with both pointer and keyboard.

When adding visual depth or disclosing overflow content, compare the open and closed states on a narrow viewport. Check the [elevation guidance](../../ui/foundations.md) and verify the intended hierarchy with long labels and real image proportions.
