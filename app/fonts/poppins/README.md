# Poppins lokal

Subset Latin Poppins normal bobot 500, 600, 700 disimpan sebagai aset repo. Sumber pengaturan tunggal adalah `app/theme/typography.js`, yang memuatnya melalui `next/font/local` dan variabel generik `--font-app`. Layout, CSS global, Material UI, Ant Design, serta grafik mengikuti konfigurasi tersebut. Panduan mengganti font: `docs/typography.md`.

Development dan build tidak mengunduh font dari internet. Lisensi SIL Open Font License disertakan pada OFL.txt, sumber https://github.com/google/fonts/tree/main/ofl/poppins.
